# 🚀 Transaction Analysis & Anomaly Detection System

A Python-based project to analyze transaction data and identify unusual patterns using rule-based logic.

---

## 📌 Project Overview

This project is a **terminal-based application** built using Python that performs basic transaction analysis and detects anomalies such as high-value transactions and duplicate entries.

It is designed to strengthen core programming concepts and can be extended into a real-world system using databases and machine learning.

---

## 🎯 Features

- 🔍 Detect high (suspicious) transactions  
- ♻️ Identify duplicate transactions  
- 📊 Category-wise spending analysis  
- 🔎 Search transactions by category  

---

## 🧠 Concepts Used

- Object Oriented Programming (OOP)  
- Lists & Data Handling  
- Loops (for iteration and logic building)  
- File Handling (CSV)  
- Basic Data Analysis Logic  

---

## 🛠️ Tech Stack

- Python  
- CSV (for data storage)
